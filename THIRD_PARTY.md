# Сторонние компоненты

## InfernoSaber

- Исходники: [fred-brenner/InfernoSaber---BeatSaber-Automapper](https://github.com/fred-brenner/InfernoSaber---BeatSaber-Automapper).
- Подключение: Git submodule `ai_engine/infernosaber`.
- Закреплённая ревизия: `b6a559fe28d407364daeeffbd06332329707270d`.
- Лицензия исходников: MIT, copyright Frederic Brenner; оригинальная лицензия находится в submodule.

## Веса и окружение AI

Исходные веса получены из [BierHerr/InfernoSaber](https://huggingface.co/BierHerr/InfernoSaber), ревизия `e0f4c8b53f4c52fc30c5b66fd7384c0ce85884ff`. Карточка модели объявляет лицензию MIT; её исходный текст сохраняется в комплекте рядом с весами. Веса и результаты дообучения отсутствуют в истории Git; публичный портативный выпуск содержит исходный профиль и два дообученных профиля, без обучающих записей. Лицензия InfernoSaber и авторские уведомления включены в комплект.

Версии TensorFlow, NumPy и других библиотек AI-окружения записаны в `ai_engine/requirements-windows.lock`. Портативный выпуск содержит отдельное CPU-окружение и уведомления о лицензиях зависимостей в каталогах `*.dist-info`. Лицензии Python, InfernoSaber и PyInstaller дополнительно собраны в `licenses`. Microsoft Visual C++ Runtime подключён app-local для Python и TensorFlow.

## FFmpeg и встроенное аудио

FFmpeg не включён в публичный ZIP. При первой обработке аудио пользовательская копия программы скачивает LGPL shared-сборку из [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds), проверяет SHA256 и сохраняет сведения об источнике и уведомления из архива. Далее используется эта локальная копия.

Публичный EXE не распространяет FMOD: PCM16-банки патчера декодируются модулем `native_audio.py`. Уже сохранённые игровые данные можно переиспользовать без декодирования. Для AI-пересоздания других сжатых FSB используется исходный MP3/ZIP.

## BeatSaver

[BeatSaver](https://beatsaver.com/) используется как источник авторских карт для локальной подготовки эталонов. Сценарии сбора сохраняют происхождение и контрольные суммы. Карты, музыка и подготовленные обучающие массивы в Git не входят; доступность карты не означает передачу прав на аудиозапись.

## Игра и локальная сборка

APK, OBB, Unity-ресурсы игры, игровые шаблоны и бинарные компоненты локального комплекта не распространяются через этот репозиторий. Названия Beat Saber и Pico используются для описания совместимости. Проект не связан с их правообладателями.

Справочник `assets/stock_packs.json` содержит структуру паков и идентификаторы уровней для распознавания совместимого кэша; аудио, текстур и исходных Unity-бандлов в нём нет.
