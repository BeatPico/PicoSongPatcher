# Pico Song Patcher 1.4

Версия 1.4 устанавливается отдельно в `dist_v4/Pico Song Patcher 1.4`.
Она получает копию локальной библиотеки. Версия 1.3.1 и её данные сохраняются
для предыдущего рабочего сценария. Программа создаёт файлы на ПК;
перенос на Pico выполняется вручную.

## Кэш и песни

1. Выберите OBB в верхней строке. Подходит оригинальный или уже изменённый
   совместимый кэш Beat Saber 1.40.8 / OVRport 3.2.2.
2. Программа читает все распознанные паки и показывает добавленные песни.
   Песни, найденные в выбранном кэше, по умолчанию отмечаются **В новую сборку**.
   Наличие сравнивается по ID конкретной версии карты.
3. **Содержимое OBB** показывает все паки, штатные и добавленные песни.
   Для добавленных песен без исходных ZIP создаётся локальная копия игровых
   данных; пригодные для этого песни можно пересоздать через AI по их аудио.
4. Выберите пак для новых песен. **Назначить выделенным** переносит в этот
   пак выбранные песни. Без назначения уже встроенные песни сохраняют свои паки.
   Доступны существующие паки; отдельная папка в Проводнике не создаёт
   новый пункт меню игры. Для нового пака нужны его определение и регистрация
   в игровых ресурсах — в этой версии используется выбор существующего.
5. Добавляйте новые карты/MP3 или пересоздавайте AI-карты, затем собирайте OBB.
   Готовые песни переиспользуются без повторного кодирования аудио.
   На очки переносится полный итоговый OBB.

## Выделение и локальное удаление

Строки можно выделять протягиванием мыши; сохраняются Ctrl и Shift.
Первый столбец включает/выключает песню для следующей сборки.

**Удалить локально** удаляет выбранные записи и принадлежащие им локальные
файлы после показа списка. **Удалить локальные вне OBB** использует точные ID
из выбранного OBB. Выгруженный кэш не изменяется. Если прочитать его снова,
содержащиеся в нём песни снова появятся в библиотеке. Для исключения песни
только из следующей сборки достаточно снять отметку.

## AI и дополнительные объекты

Выберите модель, включите **Стены** и **Бомбы**, выделите песни и нажмите
**Пересоздать AI**. Уже созданные карты меняются после пересоздания.
Кнопка **Обучить модель на эталонах** обучает модель на подготовленной
авторской подборке; выделенные песни библиотеки не являются её примерами.

Новый профиль использует встроенные боковые и потолочные стены для уклонов
и пригибания, когда это позволяет расположение блоков. Дуги создаются реже,
с меньшей кривизной, без привязки к верхнему ряду блоков. Концы дуг остаются
на блоках. Вероятность предложений бомб увеличена, проверки свободного места
сохранены. Это настройки существующего генератора объектов; улучшение весов
модели оценивается отдельно. Количество объектов зависит от песни и сложности.

Генерация фиксирует случайный генератор для каждой сложности и части песни.
Одинаковые аудио, модель и настройки дают повторяемую карту. Версия модели
и профиль объектов входят в идентификатор карты.

## Завершение сборки

При временной блокировке Windows переименование папки повторяется. Если
папка остаётся заблокирована после успешных проверок, программа возвращает
готовые файлы в рабочей папке с маркером `ГОТОВО.txt`. Такой случай больше
не требует повторного преобразования песен. Непрошедшие проверки сборки
не выдаются за готовые.

Архив, ссылки, исходные ресурсы и сохранение штатных песен проверяются на ПК.
Новые карты и перенос между паками следует проверить в игре на очках.
